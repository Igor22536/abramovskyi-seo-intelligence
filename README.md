# Abramovskyi SEO Intelligence

Windows-програма для технічного SEO-аудиту від [Ігоря Абрамовського](https://seoabramovskyi.in.ua/).

## Модулі

- **Site Spider** — сканування сайту, технічні SEO-перевірки та Excel-звіти.
- **Bulk URL Checker** — пакетна перевірка списків URL.
- **JS Render Lab** — аналіз сторінок після виконання JavaScript у вбудованому Chromium.
- **Custom Extraction** — витягування даних за CSS-селекторами та XPath.

## Системні вимоги

- Windows 10 або Windows 11, x64.
- Достатньо вільного місця для програми та вбудованого Chromium.
- Інтернет-з’єднання для сканування сайтів.

## Встановлення

1. Відкрийте [останній реліз](https://github.com/Igor22536/abramovskyi-seo-intelligence/releases/latest).
2. Завантажте `Abramovskyi-SEO-Intelligence-Setup-1.0.1.exe`.
3. Запустіть інсталятор і виконайте кроки майстра.

Python, BAT-файли та окреме завантаження Chromium не потрібні.

## Поточна версія

Версія: **1.0.1**.

Випуск виправляє конфлікт Qt DLL у Windows-збірці 1.0.0 та підтримує оновлення поверх попередньої версії.

## Обмеження

- Інсталятор наразі не має комерційного цифрового підпису; Windows SmartScreen може показати попередження.
- Програма призначена для Windows x64.
- Результати SEO-перевірок слід оцінювати з урахуванням особливостей конкретного сайту.

Вихідний код програми та приватний код сайту в цьому репозиторії не публікуються. Ліцензію буде додано окремо після узгодження умов поширення.
